# Information injection dashboard

Public, read-only summary of the information-injection research project: how many certified
bits of teacher assistance a frozen pretrained checkpoint needs to solve verifiable tasks.

Live page: https://dangxingyu.github.io/information-injection-dashboard/

The page shows the certified-accounting rules, the GPU fleet that runs the experiments, the
protocol-progress figure (mean certified bits per task by protocol version, with the
`reference` and `free` baselines), every experiment with its aggregates, a per-task view, and
the Study B checkpoint radar once it exists.

`data.json`, `experiments/*.json` and `progress.png` are generated by the project's exporter
every fifteen minutes and committed only when their content changes (at least hourly as a
keepalive). Only aggregates are published: no trajectory text, file paths, credentials or node
hostnames. Do not edit the generated files by hand; the static page (`index.html`, `app.js`,
`style.css`) is also copied from the project on every export.

Local preview: `python -m http.server 8766` in this directory, then open
`http://localhost:8766`.

Visual organization follows the [T³ dashboard](https://dangxingyu.github.io/t3-dashboard/).
